##  Database Schema Overview

### Table: `render_jobs`
**Purpose:** Track all video rendering requests

| Column | Type | Description |
|--------|------|-------------|
| id | UUID | Primary key |
| job_id | VARCHAR | Unique job identifier |
| prompt | TEXT | User's natural language prompt |
| status | VARCHAR | pending, processing, rendering, uploading, completed, failed |
| created_at | TIMESTAMP | Job creation time |
| duration_seconds | INTEGER | Total rendering time |
| error_message | TEXT | Error details if failed |

### Table: `generated_videos`
**Purpose:** Store metadata for completed videos

| Column | Type | Description |
|--------|------|-------------|
| id | UUID | Primary key |
| job_id | VARCHAR | Foreign key to render_jobs |
| video_url | TEXT | Local or storage URL |
| cdn_url | TEXT | Cloudflare R2 CDN URL |
| file_size_bytes | BIGINT | Video file size |
| duration_seconds | NUMERIC | Video duration |

### Table: `generation_logs`
**Purpose:** Detailed logs for each generation attempt

| Column | Type | Description |
|--------|------|-------------|
| id | UUID | Primary key |
| job_id | VARCHAR | Foreign key to render_jobs |
| iteration_number | INTEGER | LLM retry iteration |
| log_level | VARCHAR | DEBUG, INFO, WARNING, ERROR, CRITICAL |
| message | TEXT | Log message |
| generated_code | TEXT | Manim code generated by LLM |

##  Integration Points in main.py

The Supabase client is now initialized in `main.py`:

```python
# Initialize Supabase client (Phase 4 - Database for persistent storage)
supabase_client: Optional[Client] = None
if SUPABASE_URL and SUPABASE_KEY:
    try:
        supabase_client = create_client(SUPABASE_URL, SUPABASE_KEY)
        logger.info("Supabase client initialized successfully")
    except Exception as e:
        logger.warning(f"Failed to initialize Supabase client: {e}")
        logger.warning("Service will run without database persistence")
else:
    logger.warning("Supabase credentials not provided - database features disabled")
```

### Usage Examples:

#### Create a new job:
```python
if supabase_client:
    supabase_client.table('render_jobs').insert({
        'job_id': job_id,
        'prompt': user_prompt,
        'status': 'pending'
    }).execute()
```

#### Update job status:
```python
if supabase_client:
    supabase_client.table('render_jobs').update({
        'status': 'completed',
        'completed_at': datetime.now().isoformat(),
        'duration_seconds': duration
    }).match({'job_id': job_id}).execute()
```

#### Log generation attempts:
```python
if supabase_client:
    supabase_client.table('generation_logs').insert({
        'job_id': job_id,
        'iteration_number': iteration,
        'log_level': 'INFO',
        'message': 'Generated Manim code',
        'generated_code': code
    }).execute()
```

### Query Optimization Tips

2. Use `created_at DESC` indexes for recent jobs
3. Limit result sets with `.limit()`
4. Use `.select('column1, column2')` for specific columns

##  Troubleshooting

### Issue: "Invalid API key" error
**Solution:** Verify the key in `.env` matches the Supabase dashboard API Keys section

### Issue: "Relation does not exist"
**Solution:** Schema not executed. Run `supabase_schema.sql` in SQL Editor

### Issue: Connection timeout
**Solution:** Check network connectivity, verify project URL is correct

### Issue: RLS policy blocking queries
**Solution:** Temporarily disable RLS during development or add permissive policy
